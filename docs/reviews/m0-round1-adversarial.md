1. **High — A writable jail can supply root identities.** [cmd/qnapfilemanager/main.go:245](C:/Dev/QNAPFileManager/cmd/qnapfilemanager/main.go:245) loads identity files from inside `-jail`, even when spawning real Linux workers. With `-jail /share/Public`, a user who can create `etc/passwd` there can map their authenticated QTS username to UID 0. `Root:false` does not prevent `Credential.Uid=0`; combined with finding 3, this exposes root-readable files outside the jail. **Fix:** use trusted host identity files in Linux process mode; permit fixture identity files only in an isolated development mode.

2. **High — Removed group privileges remain usable indefinitely.** [internal/workerpool/workerpool.go:502](C:/Dev/QNAPFileManager/internal/workerpool/workerpool.go:502) reuses workers solely by UID, without comparing GID or supplementary groups. After an administrator removes Alice from a confidential-share group, session revalidation updates her principal, but her existing worker retains that group. Continued requests prevent idle eviction. **Fix:** compare normalized credentials on acquisition and retire workers when credentials change.

3. **High — `fsx.Root` is not a filesystem jail.** [internal/fsx/root.go:55](C:/Dev/QNAPFileManager/internal/fsx/root.go:55), [internal/fsops/fsops.go:258](C:/Dev/QNAPFileManager/internal/fsops/fsops.go:258). Path joining provides lexical containment only. An in-jail `escape -> /` symlink permits downloading `/escape/etc/passwd`; `O_NOFOLLOW` protects only the final component. Listing follows even final directory symlinks. No race is necessary. **Fix:** resolve operations relative to an opened root directory using traversal-resistant APIs, such as `os.Root`, with appropriate final-component restrictions.

4. **High — Authentication state permits persistent memory and CPU exhaustion.** [internal/qtsauth/verifier.go:173](C:/Dev/QNAPFileManager/internal/qtsauth/verifier.go:173), [internal/web/session.go:134](C:/Dev/QNAPFileManager/internal/web/session.go:134). Expired verifier entries are never removed unless explicitly invalidated. Distinct bogus tokens therefore accumulate permanently. One authenticated user can also repeatedly omit `qfm_sid`, creating unlimited sessions retained for 12 hours; every request scans the entire session map. **Fix:** bound both stores, evict expired entries, limit session creation per identity, and bound concurrent CGI validation.

5. **Medium — One slow authentication blocks unrelated users.** [internal/web/session.go:54](C:/Dev/QNAPFileManager/internal/web/session.go:54), [internal/web/session.go:77](C:/Dev/QNAPFileManager/internal/web/session.go:77). The global session sweep holds `s.mu` while acquiring each session mutex. Revalidation holds that session mutex across QTS HTTP calls and identity-helper execution. Consequently, one slow revalidation causes another request’s sweep to block while holding the global lock, stalling all authentication. **Fix:** perform network/helper work outside session locks and avoid acquiring session locks while holding the global map lock.

6. **Medium — Large replies can corrupt the RPC stream.** [internal/wproto/conn_linux.go:29](C:/Dev/QNAPFileManager/internal/wproto/conn_linux.go:29), [internal/worker/worker.go:231](C:/Dev/QNAPFileManager/internal/worker/worker.go:231). Nonblocking stream `sendmsg` can return a short write. A legitimate large listing—such as `limit=5000`—can exceed available socket buffering. The worker logs the error and continues, leaving a partial frame whose remainder is incorrectly filled by subsequent replies, or never arrives. **Fix:** finish partial writes under the transport lock, attaching descriptors only once; close the transport on unrecoverable framing/write errors.

7. **Medium — FIFO requests consume worker slots beyond HTTP cancellation.** [internal/fsops/fsops.go:80](C:/Dev/QNAPFileManager/internal/fsops/fsops.go:80), [internal/fsops/open_linux.go:13](C:/Dev/QNAPFileManager/internal/fsops/open_linux.go:13), [internal/worker/worker.go:225](C:/Dev/QNAPFileManager/internal/worker/worker.go:225). Listing or downloading a readable FIFO with no writer blocks at `open`, before file-type rejection. Repeating this fills the worker’s 64 slots. Request deadlines merely unregister RPC callers; workers receive the process context and continue running. EOF also waits for handlers before cancellation. **Fix:** open directories with `O_DIRECTORY`, use nonblocking opens followed by type verification for downloads, and propagate request cancellation to worker operations.

8. **Medium — Concurrent startup bypasses the worker ceiling.** [internal/workerpool/workerpool.go:571](C:/Dev/QNAPFileManager/internal/workerpool/workerpool.go:571). Capacity checks count only established workers, excluding `p.spawning`. Concurrent first requests from more than eight distinct users can all pass the check before any handshake completes, producing more than `worker.max` processes. **Fix:** reserve capacity atomically for starting workers and account for processes still terminating.

9. **Medium — Startup failures bypass the restart budget.** [internal/workerpool/workerpool.go:547](C:/Dev/QNAPFileManager/internal/workerpool/workerpool.go:547). Failed spawn/hello attempts never call `noteRestartLocked`. Repeated worker startup crashes, handshake failures, or requests cancelled during startup can therefore trigger unlimited replacement attempts despite the advertised budget. **Fix:** charge failed startup attempts, including processes started but cancelled before registration, and apply backoff.

10. **Medium — Cancellation can abandon received descriptors.** [internal/workerpool/client.go:207](C:/Dev/QNAPFileManager/internal/workerpool/client.go:207), [internal/workerpool/client.go:292](C:/Dev/QNAPFileManager/internal/workerpool/client.go:292). `deliver` removes the pending entry before sending its result. If cancellation wins the caller’s select, a received download fd can remain in the abandoned buffered channel; neither path explicitly closes it. Repeated cancelled downloads can exhaust descriptors before garbage collection eventually closes them. **Fix:** make delivery/cancellation ownership atomic and explicitly close any response descriptors abandoned during cancellation.

11. **Medium — Domain-qualified users are rejected before identity resolution.** [internal/qtsauth/cred.go:35](C:/Dev/QNAPFileManager/internal/qtsauth/cred.go:35). QTS names such as `DOMAIN\alice` are rejected by the authentication username regex, although `idmap` explicitly supports that form. Both cookie extraction and response binding reject it, preventing those users from reaching the NSS resolver. **Fix:** share a validated username grammar with `idmap`, preserving option-injection protection.

12. **Low — Non-UTF-8 symlink targets lose their authoritative bytes.** [internal/web/static/js/list.js:129](C:/Dev/QNAPFileManager/internal/web/static/js/list.js:129). “Go to symlink target” uses `linkResolved`, which crosses JSON only as a string. Invalid bytes become U+FFFD, so navigation fails or opens a different, similarly named path. **Fix:** carry a base64 representation of resolved targets and use it when constructing navigation requests.
