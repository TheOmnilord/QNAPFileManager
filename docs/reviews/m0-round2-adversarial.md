Read-only review completed; all files changed by the two fixes were read in full. The four JavaScript routing tests pass. Go/Linux execution tests were not run. **S** refers to the standard review’s bullet order; **A** to the adversarial review’s numbering.

1. **P1 — Authentication exhaustion is only partially fixed (A4).** [verifier.go:194](C:/Dev/QNAPFileManager/internal/qtsauth/verifier.go:194) bounds active validations but queues unlimited callers. Authentication also occurs before the HTTP operation deadline at [server.go:125](C:/Dev/QNAPFileManager/internal/web/server.go:125). A burst of distinct bogus credentials against slow QTS validation retains request goroutines, connections, and credentials while eight validations run; sustained traffic keeps that queue growing. **Minimal fix:** bound admission/waiters, reject overload, and apply an authentication deadline before verification. Add a rate limit to bound sustained CGI work.

2. **P2 — The worker ceiling remains partial; retirement introduces untracked workers (S6/A8).** [workerpool.go:546](C:/Dev/QNAPFileManager/internal/workerpool/workerpool.go:546) removes a credential-mismatched worker before its accepted calls finish. Capacity at line 646 counts only registered workers and pending spawns; eviction at line 665 likewise releases capacity before process exit. With `Max=1`, changing credentials during an outstanding request immediately permits a second live worker. Repeated replacements can accumulate workers outside the limit. Shutdown also collects only `p.workers` at line 305, missing these retiring workers. **Minimal fix:** track retiring/terminating workers until `exited`, count them against capacity, and include them in shutdown.

3. **P2 — Cancellation can itself block indefinitely (A7 partial; new regression).** [client.go:438](C:/Dev/QNAPFileManager/internal/workerpool/client.go:438) writes `OpCancel` synchronously without a deadline, after the caller’s context has expired. A concrete deadlock occurs with the development `net.Pipe`: the worker receives `OpBye` and waits for handlers at [worker.go:306](C:/Dev/QNAPFileManager/internal/worker/worker.go:306); the bye timeout then tries to write cancellation, but the worker is no longer reading. Consequently, termination never reaches transport closure or the kill callback. **Minimal fix:** bound transport writes and close/retire the transport when cancellation cannot be sent; do not send request cancellation for `OpBye`.

4. **P2 — Cancelled startups still bypass restart accounting (S7/A9 partial).** [workerpool.go:610](C:/Dev/QNAPFileManager/internal/workerpool/workerpool.go:610) explicitly skips charging a failed startup whenever the request context is cancelled. An authenticated caller can repeatedly disconnect after process creation but before hello completes, causing replacement processes without consuming the budget. **Minimal fix:** charge attempts once a process has started, independently of caller cancellation, or enforce a separate spawn-rate budget.

5. **P2 — Absolute symlink targets can resolve to the wrong file (new).** [fsops.go:169](C:/Dev/QNAPFileManager/internal/fsops/fsops.go:169) applies `filepath.Clean` before resolving target components. Suppose `/share/A/link -> /share/B/dir`, and another symlink targets `/share/A/link/../report`. Linux resolves that target to `/share/B/report`; this implementation removes `link/..` first and selects `/share/A/report`. The UI’s newly enabled target actions can therefore download the wrong report. Additionally, lines 116–134 discard failed/non-directory components when a subsequent `..` pops them. **Minimal fix:** preserve target components and resolve them in kernel order, propagating traversal errors before processing `..`.

6. **P2 — Domain-name support remains partial on cookie authentication (A11).** [cred.go:70](C:/Dev/QNAPFileManager/internal/qtsauth/cred.go:70) still relies on `r.Cookie`: Go rejects a literal backslash in cookie values, so `NAS_USER=DOMAIN\alice; qtoken=…` loses the username and cannot use qtoken authentication. Percent-encoding the backslash does not help because the value is not decoded before username validation. The new tests exercise the grammar and response binding, not this cookie path. **Minimal fix:** decode the supported QTS cookie representation before validation and add end-to-end tests using actual Cookie headers. SID authentication with an authoritative response username is fixed.

7. **P2 — One user can evict another user’s active sessions (A4 partial).** [session.go:107](C:/Dev/QNAPFileManager/internal/web/session.go:107) evicts the globally oldest insertion without considering its owner, expiration, or recent activity. When the total store is full, a user below their personal limit can establish another credential and invalidate another user’s actively used session. Expired entries elsewhere are not preferentially removed. **Minimal fix:** reclaim expired entries first; under remaining pressure, replace the requesting user’s session or reject creation instead of invalidating another user’s live session.

8. **P2 — Failure notification races with cancellation (new).** [client.go:252](C:/Dev/QNAPFileManager/internal/workerpool/client.go:252) reads `pending.abandoned` after releasing `c.mu`; [client.go:406](C:/Dev/QNAPFileManager/internal/workerpool/client.go:406) writes it under that mutex. A worker disconnect concurrent with an HTTP cancellation creates an unsynchronized read/write. **Minimal fix:** perform the abandonment check and nonblocking notification under `c.mu`, or remove the unnecessary check for these descriptor-free error notifications.

9. **P3 — Final-component no-follow is not strictly preserved (new).** [fsops.go:524](C:/Dev/QNAPFileManager/internal/fsops/fsops.go:524) uses `os.Root.OpenFile`, which follows confined symlinks despite the supplied `O_NOFOLLOW`; `SameFile` at line 540 checks inode identity, not whether traversal followed a link. Between the initial `Lstat` and open, rename `a` to `b` and replace `a` with a relative symlink to `b`: the open follows the final symlink and passes `SameFile`. This does not expose a different inode or escape the jail, but contradicts the explicit no-follow contract. **Minimal fix:** use a descriptor-relative final open that actually honors `O_NOFOLLOW`.
