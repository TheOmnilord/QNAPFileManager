1. **P1 — New: ZFS import failure triggers destructive recreation.** [ci-zfs-setup.sh:118](C:/Dev/QNAPFileManager/scripts/ci-zfs-setup.sh:118) treats *any* failed import of an existing image as permission to delete it, truncate a replacement, and force-create a pool.
